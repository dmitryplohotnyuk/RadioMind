Проверка чистой копии выявила отсутствие папки runtime в новом checkout;
скрипт теперь создаёт её перед pytest. Полный повторный прогон успешен.
Запуск двойным кликом проверен при отсутствии профиля, занятом порте, одновременных
кликах, путях с пробелами и сохранении состояния уже приостановленного сервиса.

11 пропусков чистой копии связаны с отсутствием необязательных моделей, нативных
библиотек и синтетического речевого материала. Это не успешная проверка этих
функций. В обоих наборах остаётся одно предупреждение Starlette/AnyIO об устаревшем
BlockingPortal.

Готовой Linux-среды не было. USB-производительность Linux, очистка под Linux,
VM/контейнер и Raspberry Pi не приняты; Pi отложен по согласованному объёму работ.
Приёмник ради этих проверок не перезапускался и не перенастраивался. Нативные
цифровые референсы проверяются отдельно; новой приёмки разборчивого голоса нет.

Экспорт содержит исходники и SOURCE_MANIFEST.json; рядом с ZIP — его SHA-256.
Эфир, базы данных, личные профили, модели и нативные бинарные файлы не публикуются.
Поиск секретов по шаблонам дополняется явным списком файлов, но не гарантирует
обнаружение абсолютно любого секрета.
