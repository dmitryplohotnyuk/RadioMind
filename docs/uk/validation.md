Перевірка чистої копії виявила відсутність папки runtime у новому checkout;
скрипт тепер створює її перед pytest. Повторний повний прогін успішний.
Запуск подвійним кліком перевірено без профілю, із зайнятим портом, одночасними
кліками, шляхами з пробілами та збереженням стану вже призупиненого сервісу.

11 пропусків чистої копії пов'язані з відсутністю необов'язкових моделей, нативних
бібліотек і синтетичного мовленнєвого матеріалу. Це не успішна перевірка цих
функцій. В обох наборах залишається одне попередження Starlette/AnyIO про застарілий
BlockingPortal.

[Запуск і журнали GitHub](https://github.com/dmitryplohotnyuk/RadioMind/actions/runs/38852045111)
фіксують першу успішну повну матрицю. Перші прогони виявили лапки в YAML і
помилки перевірки типів Windows API під Linux; обидві проблеми виправлено. Платформні
гілки також пройшли 40 локальних тестів і mypy для обох платформ. GitHub повідомляє
попередження про застарілий Node 20 runtime у зафіксованих версій Actions.

Програмні перевірки Linux виконано на GitHub Ubuntu, без локальної Linux VM та USB.
USB-продуктивність Linux, очищення під Linux,
VM/контейнер і Raspberry Pi не прийняті; Pi відкладено за узгодженим обсягом робіт.
Приймач заради перевірок не перезапускався й не переналаштовувався. Нативні цифрові
референси перевіряються окремо; нового приймання розбірливого голосу немає.

Експорт містить код і SOURCE_MANIFEST.json; поруч із ZIP — його SHA-256. Ефір,
бази даних, приватні профілі, моделі й нативні бінарні файли не публікуються.
Пошук секретів за шаблонами доповнено явним списком файлів, але він не гарантує
виявлення абсолютно будь-якого секрету.
