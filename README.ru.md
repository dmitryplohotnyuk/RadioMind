# RadioMind

![RadioMind](docs/assets/radiomind-mark.svg)

**Локальный сканер эфира и архив разговоров. Только приём.**

[English](README.md) · [Українська](README.uk.md) · [Русский](README.ru.md)

Сканирует заданные диапазоны, удерживает частоту на время разговора и затем продолжает обход. Записи сгруппированы по частотам: можно задавать названия, добавлять группы в избранное и чёрный список, слушать принятые аналоговые разговоры вживую. Интерфейс доступен на русском, украинском и английском.

[Установка и руководство пользователя](docs/ru/guide.md) · [Архитектура / форматы](docs/en/architecture.md) · [История изменений](CHANGELOG.md)

## Windows — демо

Скачайте репозиторий через **Code → Download ZIP** и распакуйте его либо
клонируйте через Git. Откройте терминал в папке проекта.

Python 3.11–3.13 x64:

```powershell
powershell -File scripts/windows/setup.ps1
powershell -File scripts/windows/start.ps1
```

После установки и настройки приёмника запускайте программу двойным кликом по
[Start RadioMind.cmd](Start%20RadioMind.cmd). Он открывает браузер и использует
уже работающий экземпляр. Настройка USB и личного RX-профиля описана в руководстве.

## Linux x64 — демо

Python 3.11–3.13:

```sh
sh scripts/linux/setup.sh
sh scripts/linux/start.sh
```

http://127.0.0.1:8765/ — демо, без USB и приёма эфира. [Установка и руководство пользователя](docs/ru/guide.md).

## Состояние

Основная проверенная на оборудовании платформа — Windows x64. Для Linux x64 подготовлены установка и CI; реальный приём под Linux ещё требует проверки. Raspberry Pi пока отложен. Очистка копий через RNNoise доступна только в Windows. Цифровые форматы экспериментальные; сопровождения транкинга и расшифровки защищённых разговоров нет.
