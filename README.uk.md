# RadioMind

![RadioMind](docs/assets/radiomind-mark.svg)

**Локальний сканер ефіру та архів розмов. Лише приймання.**

[English](README.md) · [Українська](README.uk.md) · [Русский](README.ru.md)

Сканує задані діапазони, утримує частоту на час розмови та продовжує обхід після її завершення. Записи згруповано за частотами: можна змінювати назви, додавати групи до обраного й чорного списку, слухати прийняті аналогові розмови наживо. Інтерфейс доступний українською, англійською та російською.

## Windows — демо

Завантажте репозиторій через **Code → Download ZIP** і розпакуйте його або
клонуйте через Git. Відкрийте термінал у папці проєкту.

Python 3.11–3.13 x64:

```powershell
powershell -File scripts/windows/setup.ps1
powershell -File scripts/windows/start.ps1
```

Після встановлення й налаштування приймача запускайте програму подвійним кліком по
[Start RadioMind.cmd](Start%20RadioMind.cmd). Він відкриває браузер і використовує
вже запущений екземпляр. Налаштування USB та приватного RX-профілю описано в посібнику.

## Linux x64 — демо

Python 3.11–3.13:

```sh
sh scripts/linux/setup.sh
sh scripts/linux/start.sh
```

http://127.0.0.1:8765/ — демо, без USB та приймання ефіру. [Встановлення та посібник користувача](docs/uk/guide.md).

## Стан

Основна перевірена на обладнанні платформа — Windows x64. Для Linux x64 підготовлено встановлення та CI; реальне приймання під Linux ще потребує перевірки. Raspberry Pi поки відкладено. Очищення копій через RNNoise доступне лише у Windows. Цифрові формати експериментальні; супроводу транкінгу й розшифрування захищених розмов немає.
